# RhythmTypingGame — DaKEN (打鍵)

A single-player web game combining rhythm gameplay, typing practice, and language learning. Notes approach (falling topdown) in sync with audio, and players type the corresponding text at the right time.

Japanese (romaji) and English. Built with Next.js + TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

See `docs/ROADMAP.md` for the plan.
